SQL desde cero, sobre una base real

La ruta completa de SQL sobre PostgreSQL, usando Northwind como único dataset de principio a fin. Cada consulta del material está ejecutada contra la base antes de escribirse.

12Bloques
57Temas
12Tablas
northwind=>
SELECT c.company_name, count(*) AS pedidos
FROM customers c
JOIN orders o ON o.customer_id = c.customer_id
GROUP BY c.company_name
ORDER BY pedidos DESC
LIMIT 4;
